<CodeGroup>
  ```bash curl
  # Say "Welcome" in Hausa, with Nadia's voice
  curl https://api.namuai-lab.com/v1/speech \
    -H "Authorization: Bearer $NAMU_API_KEY" \
    -d '{"text": "Sannu da zuwa!", "voice": "nadia"}' \
    -o welcome.wav
  ```

  ```python Python
  import os, requests

  audio = requests.post(
      "https://api.namuai-lab.com/v1/speech",
      headers={"Authorization": f"Bearer {os.environ['NAMU_API_KEY']}"},
      json={"text": "Sannu da zuwa!", "voice": "nadia"},
  ).content
  open("welcome.wav", "wb").write(audio)
  ```

  ```javascript JavaScript
  const res = await fetch("https://api.namuai-lab.com/v1/speech", {
    method: "POST",
    headers: { Authorization: `Bearer ${process.env.NAMU_API_KEY}` },
    body: JSON.stringify({ text: "Sannu da zuwa!", voice: "nadia" }),
  });
  const audio = Buffer.from(await res.arrayBuffer());
  ```

<p className="namu-section-label">Which endpoint should I use?</p>

| You want to… | Endpoint | Model | Why |
| --- | --- | --- | --- |
| Read a message aloud | `/v1/speech` | `speech-synthesis` | Hausa, Zarma or French, in a voice you choose |
| Turn a voice note into text | `/v1/transcribe` | `speech-recognition` | Accepts WhatsApp audio as it is |
| Let Hausa and French speakers understand each other | `/v1/translate` | `translation` | Text or speech in, text and speech out, in one call |
| Answer people by voice | `/v1/converse` | `voice-agent` | Hears, replies and speaks in Hausa (research preview) |
