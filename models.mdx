Each endpoint has one model behind it, named after its task. You never pick a model in a request: call the endpoint and the API uses the model that serves it. The list is also live at [`GET /v1/models`](/api-reference/models-and-voices/list-models), which needs no key.

## Older names

On 7 November 2026 the models took the names of their tasks. If you see the old names in an older integration or message, they are the same models:

| Today | Before 7 November 2026 |
| --- | --- |
| `speech-recognition` | `tatsuniya` |
| `speech-synthesis` | `tafiya` |
| `translation` | `kora` |
| `voice-agent` | `air` |

Requests never name a model, so nothing in your code needs to change.

## Things to know

- **Transcripts** come in lower case, without punctuation.
- **Speech** comes back as WAV by default; ask for `opus` for the smallest files ([audio formats](/guides/audio-formats)).
- **The first request after a quiet spell** is slower while the model wakes up. Allow up to a couple of minutes on that first call, and keep a generous timeout.
- **Where the work happens.** `speech-recognition` and `speech-synthesis` run on Namu's own models. `translation` and the `voice-agent`'s replies are written by Google Gemini through OpenRouter, which receives the text they work on.
- **Native review.** The Hausa and Zarma examples in these docs have not all been reviewed by native speakers yet. If you see a mistake, [tell us](/resources/support).
