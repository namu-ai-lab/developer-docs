## URL de base

```text
https://api.namuai-lab.com
```

Tous les points d’accès se trouvent sous `/v1`. Les requêtes et les réponses passent uniquement par HTTPS.

## Conventions

- **Authentification :** `Authorization: Bearer namu_sk_...`. Voir [Authentification](/fr/api-reference/authentication).
- **Corps :** du JSON pour le texte (`/v1/speech`, traduction de texte) ; pour l’audio, du multipart avec un champ `file`, ou l’audio brut comme corps.
- **Erreurs :** toujours `{"error": {"type", "message", "request_id"}}`. Voir [Erreurs](/fr/api-reference/errors).
- **Identifiants de requête :** chaque réponse porte un en-tête `X-Request-Id`.
- **Pas encore de diffusion en continu :** chaque réponse arrive en entier.
- **Versions :** la version figure dans le chemin (`/v1`). Des champs peuvent être ajoutés aux réponses à tout moment ; tout ce qui casserait une intégration est annoncé à l’avance dans l’[historique des versions](/fr/resources/changelog).
