Derrière chaque point d’accès se trouve un modèle, nommé d’après sa tâche. Vous ne choisissez jamais de modèle dans une requête : appelez le point d’accès, et l’API utilise le modèle qui le sert. La liste est aussi disponible en direct sur [`GET /v1/models`](/fr/api-reference/models-and-voices/list-models), sans clé.

## Langues par modèle

| Modèle | Haoussa `ha` | Zarma `dje` | Français `fr` |
| --- | :---: | :---: | :---: |
| `speech-recognition` | ✓ | ✓ | ✓ |
| `speech-synthesis` | ✓ | ✓ | ✓ |
| `translation` | ✓ | | ✓ |
| `voice-agent` | ✓ | | |

La traduction fonctionne uniquement entre le haoussa et le français, dans les deux sens. La traduction du zarma n’est pas encore dans l’API.

## Anciens noms

Le 7 novembre 2026, les modèles ont pris le nom de leur tâche. Si vous voyez les anciens noms dans une intégration ou un message plus ancien, ce sont les mêmes modèles :

| Aujourd’hui | Avant le 7 novembre 2026 |
| --- | --- |
| `speech-recognition` | `tatsuniya` |
| `speech-synthesis` | `tafiya` |
| `translation` | `kora` |
| `voice-agent` | `air` |

Les requêtes ne nomment jamais de modèle : rien ne doit changer dans votre code.

## À savoir

- **Les transcriptions** arrivent en minuscules, sans ponctuation.
- **La parole** revient en WAV par défaut ; demandez `opus` pour les fichiers les plus petits ([formats audio](/fr/guides/audio-formats)).
- **La première requête après un moment d’inactivité** est plus lente, le temps que le modèle se réveille. Prévoyez jusqu’à deux minutes environ pour ce premier appel, et gardez un délai d’attente généreux.
- **Où le travail est fait.** `speech-recognition` et `speech-synthesis` tournent sur les propres modèles de Namu. Les traductions de `translation` et les réponses de `voice-agent` sont rédigées par Google Gemini via OpenRouter, qui reçoit le texte à traiter.
- **Relecture par des locuteurs natifs.** Les exemples en haoussa et en zarma de cette documentation n’ont pas encore tous été relus par des locuteurs natifs. Si vous voyez une erreur, [dites-le-nous](/fr/resources/support).
