# Contributing to the Namu API docs

Thank you for helping. Small fixes (a typo, a broken link, a wrong Hausa or Zarma word) are very welcome.

1. Fork the repository, or branch from `main` if you are on the Namu team.
2. Preview with `npm i -g mint && mint dev` (Mintlify's CLI needs Node 20 or 22), then run `mint broken-links`.
3. Write plainly, for a developer on a phone in Niamey or Kano: short sentences, real commands, code that runs.
4. Every fact comes from how the API behaves or from a measurement. Mark Hausa and Zarma text for native review.
5. Open a pull request into `main`. Merging it deploys the site.

Changes to the libraries themselves belong in [namu-ai-lab/namu-sdks](https://github.com/namu-ai-lab/namu-sdks).
