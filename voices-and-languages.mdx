Every voice is used with its speaker's consent. The API does not offer voice cloning, and a voice whose consent could not be confirmed was withdrawn: a request that names it gets `400 unknown_voice`, never another voice in its place.

## Choosing the language

A voice speaks its first language unless you say otherwise. To make Mouhamad speak Hausa:

```json
{ "text": "Sannu! Yaya kuke?", "voice": "mouhamad", "language": "ha" }
```

Asking a voice for a language it does not speak returns `400 unsupported_language`, with the languages it does speak in the message.

## Get the list in code

```bash
curl https://api.namuai-lab.com/v1/voices
```

```json
{
  "data": [
    { "id": "nadia", "languages": ["ha"], "language": "ha", "description": "Warm and patient (female)" },
    { "id": "warm", "languages": ["ha"], "language": "ha", "description": "Alias of nadia" },
    { "id": "fr", "languages": ["fr"], "language": "fr", "description": "French reference voice" },
    { "id": "mouhamad", "languages": ["dje", "ha"], "language": "dje", "description": "Male; Zarma and Hausa" }
  ]
}
```

No key is needed. Read it when your app starts if you show a voice picker, so a new voice appears without an update.
