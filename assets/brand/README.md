# Namu brand assets

The logo, icon, and app icon SVG files are the approved arc-and-dot Namu assets copied from the Namu brand asset suite. `namu-palette.svg` is a documentation preview built from the approved color values.

Use `namu-logo-transparent-dark.svg` on a light surface and `namu-logo-transparent-light.svg` on a dark surface. Use a file named `on-*` when the background must travel with the mark.

Do not edit the geometry, proportions, type, gradient, or colors in these files. See `design/logo-and-assets.mdx` for the full usage rules.
