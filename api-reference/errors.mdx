```json
{
  "error": {
    "type": "text_too_long",
    "message": "'text' must be 2000 characters or fewer.",
    "request_id": "3f2a9c1e5b7d4e8fa0c2b6d9e1f3a5c7"
  }
}
```

<ResponseField name="error.type" type="string">
  A stable code. Branch on this.
</ResponseField>

<ResponseField name="error.message" type="string">
  What happened, for developers. It may change; do not parse it.
</ResponseField>

<ResponseField name="error.request_id" type="string">
  The same as the `X-Request-Id` header. Send it to us with any question about a request.
</ResponseField>
