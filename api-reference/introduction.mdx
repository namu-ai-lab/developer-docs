## Base URL

```text
https://api.namuai-lab.com
```

Every endpoint lives under `/v1`. Requests and responses use HTTPS only.

## Conventions

- **Authentication:** `Authorization: Bearer namu_sk_...`. See [authentication](/api-reference/authentication).
- **Bodies:** JSON for text (`/v1/speech`, text translation); multipart with a `file` field, or the raw audio as the body, for audio.
- **Errors:** always `{"error": {"type", "message", "request_id"}}`. See [errors](/api-reference/errors).
- **Request ids:** every response has an `X-Request-Id` header.
- **No streaming yet:** every response arrives whole.
- **Versioning:** the version is in the path (`/v1`). Fields can be added to responses at any time; anything that would break an integration comes with notice in the [changelog](/resources/changelog).
