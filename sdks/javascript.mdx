## Install

```bash
npm install namu-ai
```

Node 18 or later, Deno, Bun or Cloudflare Workers. Types are included. Then set your key:

```bash
export NAMU_API_KEY="namu_sk_..."
```

<Warning>
  Server-side only. Do not import this client in code that runs in a browser or a React Native app: the key would travel with it.
</Warning>

## Quickstart

```typescript
import { writeFile, readFile } from "node:fs/promises";
import { Namu } from "namu-ai";

const namu = new Namu(); // reads NAMU_API_KEY

// Text to speech
const audio = await namu.speech("Sannu da zuwa! Muna farin cikin jin muryarku.", { voice: "nadia", format: "mp3" });
await writeFile("welcome.mp3", Buffer.from(audio));

// Speech to text
const { text } = await namu.transcribe(await readFile("welcome.mp3"), { language: "ha" });
console.log(text);
```

## Errors

Every error is a `NamuError`, with a class per status (the same as the [Python library](/sdks/python#errors)):

```typescript
import { NamuError, QuotaExceededError, BadRequestError, APIConnectionError } from "namu-ai";

try {
  await namu.speech(text);
} catch (err) {
  if (err instanceof QuotaExceededError) { /* this month's allowance is used */ }
  else if (err instanceof BadRequestError) console.error(err.type, err.message);
  else if (err instanceof APIConnectionError) { /* the API could not be reached, even after the retries */ }
  else if (err instanceof NamuError) console.error(err.status, err.type, err.requestId);
  else throw err;
}
```

## Retries and timeouts

Network errors, `429 rate_limited` and `502`/`503`/`504` are retried up to 3 times (`Retry-After`, or 1, 2, 4 seconds); `quota_exceeded` and other `4xx` never are. The default timeout is 5 minutes.

```typescript
const namu = new Namu({ timeoutMs: 120_000, maxRetries: 5 });
```

## In an Express server

```typescript
import express from "express";
import { Namu, NamuError } from "namu-ai";

const app = express();
const namu = new Namu();
app.use(express.json());

app.post("/speak", async (req, res) => {
  // check your own user here before spending your allowance
  try {
    const audio = await namu.speech(req.body.text, { voice: "nadia", format: "mp3" });
    res.type("audio/mpeg").send(Buffer.from(audio));
  } catch (err) {
    if (err instanceof NamuError) res.status(err.status).json({ error: err.type });
    else res.status(502).json({ error: "unavailable" });
  }
});

app.listen(3000);
```

## Configuration

| Option | Environment | Default |
| --- | --- | --- |
| `apiKey` | `NAMU_API_KEY` | none |
| `baseUrl` | `NAMU_BASE_URL` | `https://api.namuai-lab.com` |
| `timeoutMs` | | 300000 |
| `maxRetries` | | 3 |
| `fetch` | | `globalThis.fetch` |

Every response is typed: `Transcription`, `Translation`, `ConverseTurn`, `Usage`, `VoiceInfo`, `Model`.
