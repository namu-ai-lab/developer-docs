When a request fails, the API answers with an HTTP status and this body:

```json
{
  "error": {
    "type": "unknown_voice",
    "message": "Unknown voice. Try one of: nadia, warm, fr, mouhamad.",
    "request_id": "3f2a9c1e5b7d4e8fa0c2b6d9e1f3a5c7"
  }
}
```

- **`type`** is stable: branch on it in your code.
- **`message`** is written for a developer. It can change, so do not parse it, and do not show it to your users as is.
- **`request_id`** is also in the `X-Request-Id` header of every response, successful or not. Include it when you [write to us](/resources/support).

## What to do with each status

| Status | Meaning | Retry? |
| --- | --- | --- |
| `400` | The request is not usable as sent | No: fix the request |
| `401` | No key, not a Namu key, or a revoked key | No: fix the key |
| `403` | The key may not do this, or the account is paused | No |
| `404` / `405` | No such endpoint, or wrong method | No |
| `413` | Too large: file, audio length or text | No: make it smaller |
| `415` | The audio could not be read | No: send another format |
| `422` | No speech was found in the audio | Ask the person to speak again |
| `429` | Rate limit or monthly allowance reached | `rate_limited`: yes, after `Retry-After`. `quota_exceeded`: no |
| `500`, `502`, `503`, `504` | Something failed on our side | Yes, with a pause |

A request that fails counts nothing against your allowance.

## Handling errors in code

<CodeGroup>
  ```python Python
  response = requests.post(url, headers=headers, json=body, timeout=300)
  if not response.ok:
      error = response.json()["error"]
      if error["type"] == "quota_exceeded":
          tell_user("Voice is resting until next month.")
      elif response.status_code in (429, 502, 503, 504):
          retry_later(error["request_id"])
      else:
          log.error("Namu API %s: %s (%s)", error["type"], error["message"], error["request_id"])
  ```

  ```javascript JavaScript
  const response = await fetch(url, { method: "POST", headers, body });
  if (!response.ok) {
    const { error } = await response.json();
    if (error.type === "quota_exceeded") showMessage("Voice is resting until next month.");
    else if ([429, 502, 503, 504].includes(response.status)) retryLater(error.request_id);
    else console.error(`Namu API ${error.type}: ${error.message} (${error.request_id})`);
  }
  ```
</CodeGroup>
